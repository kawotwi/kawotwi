## 🎯 Quick Start (5 Minutes)

### Step 1: Customize Basic Information (2 minutes)

1. **Open all HTML files** in a text editor (VS Code, Sublime, Notepad++)

2. **Find and replace** these placeholders in ALL files:
   - `Your Name` → Your actual name
   - `your.email@example.com` → Your email
   - `linkedin.com/in/yourprofile` → Your LinkedIn
   - `github.com/yourusername` → Your GitHub

3. **Save all files**

### Step 2: Add Your Content (2 minutes minimum)

1. **Update index.html**:
   - Edit project titles and descriptions
   - Update technology tags

2. **Update about.html**:
   - Write a brief introduction
   - Update skills lists

3. **Update contact.html**:
   - Verify all contact information is correct

4. **Update one project page** (projects/project-1.html):
   - Add real project information
   - Update project sections

### Step 3: Deploy to GitHub (1 minute)

1. **Go to GitHub.com** and sign in
2. **Create new repository** named `yourusername.github.io`
3. **Upload all files** (drag and drop)
4. **Wait 2-5 minutes**
5. **Visit** `https://yourusername.github.io`

Done! Your portfolio is live! 🎉

## 🖼️ Adding Your Images

1. **Collect your project images**:
   - Recommended size: 800x600px or similar
   - Format: JPG or PNG
   - Keep file sizes under 500KB

2. **Name them descriptively**:
   - Good: `drone-autonomous-flight.jpg`
   - Bad: `IMG_1234.jpg`

3. **Place in assets folder**:
   - All images go in `assets/` directory

4. **Update HTML references**:
   - Homepage: `<img src="assets/your-image.jpg">`
   - Project pages: `<img src="../assets/your-image.jpg">`

## 🆘 Common Issues

### "My images aren't showing"
- Check file paths are correct
- Verify images are in `assets/` folder
- Check file extensions match (case-sensitive)

### "CSS isn't loading"
- Verify `styles.css` exists in root directory
- Check `<link>` tag in HTML
- Clear browser cache (Ctrl+Shift+R)

### "GitHub Pages isn't working"
- Repository must be named `username.github.io`
- Repository must be public
- Wait 5-10 minutes for first deployment
- Check repository Settings → Pages

### "Git isn't working"
- See `GIT_WORKFLOW.md` for detailed troubleshooting
- Ensure Git is installed: `git --version`
- Check authentication is set up
