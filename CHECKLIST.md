# Customization Checklist

Use this checklist to ensure you've personalized all parts of your portfolio before deployment.

## 🎯 Quick Start Priority

Complete these items first for a functional portfolio:

- [ ] Replace "Your Name" in ALL HTML files
- [ ] Update navigation title in ALL HTML files
- [ ] Replace footer "Your Name" in ALL HTML files
- [ ] Add at least 3 project images to `assets/` folder
- [ ] Update contact email in `contact.html`
- [ ] Update at least one project page with real content

## 📄 Homepage (`index.html`)

- [ ] Update page title: `<title>Your Name - Robotics Portfolio</title>`
- [ ] Update navigation title: `<h1 class="nav-title">Your Name</h1>`
- [ ] Update footer name: `<strong>Your Name</strong>`

### For Each Project Card:
- [ ] Replace project image path
- [ ] Update project title
- [ ] Write project description (1-2 sentences)
- [ ] Update technology tags
- [ ] Update link to project page
- [ ] Ensure image file exists in `assets/` folder

## 👤 About Page (`about.html`)

- [ ] Update page title
- [ ] Replace "Your Name" in navigation and footer
- [ ] Write personal introduction (2-3 paragraphs)
- [ ] Update subtitle (e.g., "Robotics Engineer | Software Developer")

### Skills Section:
- [ ] Update Programming Languages list
- [ ] Update Robotics & AI skills
- [ ] Update Tools & Frameworks
- [ ] Update Hardware & Electronics skills
- [ ] Add or remove skill categories as needed

### Additional Sections:
- [ ] Write about research interests
- [ ] Add personal interests/hobbies
- [ ] Include educational background

## 📧 Contact Page (`contact.html`)

- [ ] Update page title
- [ ] Replace "Your Name" in navigation and footer
- [ ] Update email address (replace `your.email@example.com`)
- [ ] Update LinkedIn URL (replace `yourprofile`)
- [ ] Update GitHub URL (replace `yourusername`)
- [ ] Update location (City, State/Country)
- [ ] Test all links work correctly

## 📝 Resume Page (`resume.html`)

- [ ] Update page title
- [ ] Replace "Your Name" in navigation and footer
- [ ] Update subtitle if needed

### Education Section:
- [ ] Add Master's degree information
  - [ ] University name
  - [ ] Expected graduation date
  - [ ] Relevant coursework
- [ ] Add Bachelor's degree information
  - [ ] University name
  - [ ] Graduation date
  - [ ] GPA (if impressive)
  - [ ] Relevant coursework

### Experience Section:
- [ ] Add work experience entries (at least 2-3)
  - [ ] Position title
  - [ ] Company name
  - [ ] Location
  - [ ] Dates (Start - End)
  - [ ] 3-5 bullet points of achievements
- [ ] Order by most recent first

### Technical Skills:
- [ ] Update programming languages
- [ ] Update robotics & AI skills
- [ ] Update tools & frameworks
- [ ] Update hardware skills

### Optional Sections:
- [ ] Add publications (if any)
- [ ] Add presentations
- [ ] Add awards & honors
- [ ] Add certifications

## 🤖 Project Pages (`projects/*.html`)

### For EACH project page:

- [ ] Update page title: `<title>Project Name - Your Name</title>`
- [ ] Replace "Your Name" in navigation and footer
- [ ] Update project title in header
- [ ] Update technology tags
- [ ] Add/replace project image

### Content Sections:
- [ ] Write Overview (2-3 paragraphs)
- [ ] List Objectives (3-5 points)
- [ ] Describe Technical Approach
  - [ ] List key components
  - [ ] Explain technologies used
- [ ] Detail Implementation
- [ ] Share Results
  - [ ] Include metrics if available
  - [ ] Add videos or GIFs if possible
- [ ] List Future Work items
- [ ] Update GitHub repository link

### Image Paths:
- [ ] Verify main project image path: `../assets/your-image.jpg`
- [ ] Add additional images if needed
- [ ] Ensure all images are properly named and in assets folder

## 🖼️ Images & Assets

- [ ] Replace `placeholder.jpg` with real project images
- [ ] Ensure all project images are:
  - [ ] High quality (minimum 800x600px)
  - [ ] Similar aspect ratios (preferably 4:3 or 16:9)
  - [ ] Optimized file size (< 500KB each)
  - [ ] Professional looking
- [ ] Use descriptive filenames (e.g., `drone-autonomous-flight.jpg`)
- [ ] All images in `assets/` folder

## 🎨 Styling (Optional)

If you want to customize colors:
- [ ] Open `styles.css`
- [ ] Update CSS variables in `:root` section:
  ```css
  --primary-color: #2c3e50;      /* Your color */
  --secondary-color: #3498db;     /* Your color */
  --accent-color: #e74c3c;        /* Your color */
  ```

## 📱 Testing Checklist

Before deploying:

### Functionality Tests:
- [ ] All navigation links work
- [ ] All project links work
- [ ] External links (GitHub, LinkedIn, email) work
- [ ] All images display correctly
- [ ] CSS styling loads properly

### Content Review:
- [ ] Spell-check all text
- [ ] Grammar check all text
- [ ] No lorem ipsum or placeholder text
- [ ] No "Your Name" placeholders remaining
- [ ] Professional tone throughout

### Responsive Testing:
- [ ] View on desktop (1920x1080)
- [ ] View on laptop (1366x768)
- [ ] View on tablet (768x1024)
- [ ] View on mobile (375x667)
- [ ] All content readable on small screens
- [ ] Navigation works on mobile

### Browser Testing:
- [ ] Test in Chrome
- [ ] Test in Firefox
- [ ] Test in Safari (if available)
- [ ] Test in Edge

## 🚀 Deployment Checklist

- [ ] Create GitHub repository named `username.github.io`
- [ ] Upload all files to repository
- [ ] Verify GitHub Pages is enabled
- [ ] Wait for deployment (2-5 minutes)
- [ ] Visit live site and test
- [ ] Share URL with friends for feedback

## 📢 After Deployment

- [ ] Add website link to:
  - [ ] LinkedIn profile
  - [ ] GitHub profile README
  - [ ] Resume
  - [ ] Business cards
  - [ ] Email signature
- [ ] Share on social media
- [ ] Submit to portfolio directories

## 🔄 Ongoing Maintenance

Set reminders to:
- [ ] Add new projects quarterly
- [ ] Update resume semi-annually
- [ ] Refresh skills list as you learn
- [ ] Update profile photo/avatar if changed
- [ ] Check all links still work
- [ ] Update contact information if changed

---

## Priority Levels

### 🔴 Critical (Do These First)
- Personal information (name, email, links)
- At least one complete project page
- Contact information
- Basic about section

### 🟡 Important (Do Soon)
- All project pages filled out
- Complete resume
- All skills updated
- Multiple project images

### 🟢 Nice to Have (When Time Permits)
- Custom colors
- Additional projects
- Publications section
- Professional photos

---

**Pro Tip**: Don't aim for perfection on your first deployment. Get a functional version live, then iterate and improve over time. An online portfolio with 3-4 good projects is better than a perfect portfolio that never launches!

Save this checklist and check items off as you complete them. Good luck! 🚀
